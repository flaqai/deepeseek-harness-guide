# Руководство по использованию DeepSeek Harness

[English](USAGE.md) · [简体中文](USAGE_zh.md)

Это краткое руководство на русском языке. DeepSeek Harness находится в предварительной версии для разработчиков; сверяйте команды с используемым коммитом и официальной документацией.

## Быстрый старт

```bash
npx @deepseek-ai/dsh web
dsh --profile web --dump-config
```

Откройте `http://127.0.0.1:3080`, настройте модель и начните с временного рабочего пространства. Вторая команда выводит дерево плагинов, собранное из Profile, Bundle и Patch.

## Категории модулей

- Композиция runtime: Context, Service, Fiber, Effect, Event и Loader.
- Выполнение агента: адаптер, Prompt, Agent Loop, инструменты, политика, подтверждение и песочница.
- Состояние: события Session, память, сжатие и воспроизведение.
- Интерфейс: Host, удалённый API, Web Client, desktop, TUI и mobile.
- Экосистема: процессы, браузер, зрение, интеграции, темы и средства разработки.

## Безопасная установка

```bash
dsh plugin --profile demo add <package-or-git-spec>
dsh --profile demo --dump-config
```

Зафиксируйте Git-коммит и проверьте лицензию, установочные скрипты, сеть, файлы, дочерние процессы, секреты и хранение данных. Во временном Profile проверьте запуск, отказ, тайм-аут, выгрузку, перезапуск и откат.

## Практические Skills

В [`skills/`](skills/) находятся четыре Agent Skill для исследования репозитория, создания плагина, разработки инструмента и аудита плагина. Skill руководит разработкой, но не является плагином DSH Runtime.

Полные процедуры, диагностика и checklist публикации приведены в [английском руководстве](USAGE.md).
